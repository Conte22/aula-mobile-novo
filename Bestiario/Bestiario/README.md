# Bestiario

Projeto base em JavaScript com Expo SDK 57, React Native e Expo Router.

## Executar

```bash
npm install
npm start
```

Também estão disponíveis `npm run android`, `npm run ios` e `npm run web`.

As telas ficam em `src/app`. A rota inicial está em `src/app/index.js` e a navegação em `src/app/_layout.js`.
